# NOIR & CO. — Premium React Website

A high-end single-page React/Vite experience inspired by the supplied legal-services and creative-portfolio references, but redesigned as one cohesive premium brand system.

## Run

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (normally http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Included

- Responsive desktop/tablet/mobile layout
- Glass navigation with scroll progress
- Dark/light theme toggle
- Hero with layered imagery and floating cards
- Services / expertise
- Filterable case-study grid
- Animated marquee
- Process / methodology
- Testimonial slider
- Insights section
- FAQ accordion
- Validated contact form success state
- Premium typography, spacing, editorial layout and responsive behavior

Replace the demo copy, email, phone number and image URLs with the client's real brand assets before launch.
